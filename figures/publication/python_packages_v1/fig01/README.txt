Rebuild: python draw.py
Dependencies: pip install -r requirements.txt; Arial must be installed.
The default width is 183 mm. Axis labels and units are 14 pt; all other visible text is at least 14 pt.
Optional: python draw.py --width-mm 260
SVG text is live and editable. PNG files are previews (300 and 600 dpi).
Maps are unchanged raster inputs embedded in the SVG. No figure title is drawn. The caption is stored separately.
data.csv is the plotted-data extract; provenance.json identifies the registered source files.
